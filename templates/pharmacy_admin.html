Rollback and restore

A snapshot is a JSON copy of the pharmacy tables. Restore is two steps on purpose: preview shows exactly which rows would change, then the confirm button sends the snapshot checksum back so a stale page cannot write the wrong state. Before restoring, the current state is captured as a PRE_RESTORE snapshot - so a wrong rollback is itself undoable.
